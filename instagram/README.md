## 실행 시점
목요일 실행은 비어 있는 날짜만 채웁니다. 월요일 TOP 5는 최신 뉴스를 쓰도록 바로 다음 월요일 것(4일 뒤)을 만들고, 수·금·토는 그다음 주까지 미리 만들어도 됩니다.

## 만드는 법
1. `queue/YYYY-MM-DD/card.json`을 쓰고(형식은 `scripts/ig_card.js` 맨 위 설명, 예시는 기존 폴더), `node scripts/ig_card.js queue/.../card.json`으로 `1.jpg`를 만듭니다. 이미지를 직접 열어 글자 넘침·겹침이 없는지 확인합니다.
2. `caption.txt`: 첫 줄 "시리즈명 번호 | 제목 + 이모지 1개", 본문은 이미지 내용을 풀어 쓰기, 통계·규제는 출처와 기준 시점, 마지막은 "🌍 전체 지도는 프로필 링크에서" + 해시태그 7~9개.
3. 뉴스와 기업 정보는 지도 데이터(매시간 수집)에서 가져오고, 수치·투자 금액 같은 사실은 기사로 다시 확인합니다. 확인 못 한 사실은 쓰지 않습니다.
4. `python3 scripts/ig_post.py`를 `POST_DATE=날짜`로 실행하면 큐 검사(dry run)를 합니다.
